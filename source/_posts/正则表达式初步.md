## 什么是正则表达式？

**正则表达式（Regular Expression，简称 regex 或 regexp）** 是一种用于**描述字符串模式**的工具。它使用一个特殊的字符串来定义一个**搜索模式**，然后可以用这个模式来对文本进行**搜索、匹配、替换或分割**等操作。

**核心思想**：你不是在寻找一个固定的字符串（如 "hello"），而是在寻找一种**模式**（如 "以 h 开头，后面跟着 4 个小写字母，最后以 o 结尾"）。

<!--more-->

**应用场景**：

- **数据验证**：邮箱、电话号码、身份证号格式校验
- **文本搜索**：在代码或文档中快速查找特定模式的字符串
- **文本替换**：批量修改文件中的内容
- **字符串提取**：从日志文件、HTML 或 JSON 中提取特定部分的数据
- **文本分割**：按照复杂的规则拆分字符串

## 基本语法和元字符

正则表达式由**普通字符**（如字母、数字）和**元字符**（具有特殊含义的字符）组成。

### 1. 单个字符匹配

| 元字符   | 含义                                           | 示例       | 匹配示例                |
| -------- | ---------------------------------------------- | ---------- | ----------------------- |
| `.`      | **匹配任意单个字符**（除了换行符）             | `a.b`      | "aab", "a5b", "a b"     |
| `\d`     | **匹配任意一个数字**                           | `\d\d`     | "12", "05", "99"        |
| `\D`     | **匹配任意一个非数字**                         | `\D\D`     | "ab", "#$", "我 "       |
| `\w`     | **匹配字母、数字、下划线**                     | `\w\w`     | "a1", "B_", "中文"      |
| `\W`     | **匹配非字母、数字、下划线**                   | `\W\W`     | "@#", "! ", "？"        |
| `\s`     | **匹配任意空白字符**                           | `a\sb`     | "a b"                   |
| `\S`     | **匹配任意非空白字符**                         | `a\Sb`     | "a+b", "a5b"            |
| `[...]`  | **字符集**，匹配方括号内的任意一个字符         | `[aeiou]`  | "a", "e", "i", "o", "u" |
| `[^...]` | **否定字符集**，匹配不在方括号内的任意一个字符 | `[^aeiou]` | "b", "1", "@"           |
| `[a-z]`  | **字符范围**                                   | `[0-9A-F]` | 十六进制数字            |

### 2. 数量限定（量词）

| 量词    | 含义                 | 示例      | 匹配示例            |
| ------- | -------------------- | --------- | ------------------- |
| `*`     | **匹配 0 次或多次**  | `ab*c`    | "ac", "abc", "abbc" |
| `+`     | **匹配 1 次或多次**  | `ab+c`    | "abc", "abbc"       |
| `?`     | **匹配 0 次或 1 次** | `colou?r` | "color", "colour"   |
| `{n}`   | **匹配确定的 n 次**  | `a{3}`    | "aaa"               |
| `{n,}`  | **匹配至少 n 次**    | `a{2,}`   | "aa", "aaa", "aaaa" |
| `{n,m}` | **匹配 n 到 m 次**   | `a{2,4}`  | "aa", "aaa", "aaaa" |

**贪婪匹配**：默认匹配尽可能长的字符串

- `a.*b` 匹配 "aabab" 整个字符串

**非贪婪匹配**：在量词后加 `?`，匹配尽可能短的字符串

- `a.*?b` 匹配 "aabab" 中的 "aab" 和 "ab"

### 3. 位置限定（锚点）

| 锚点 | 含义               | 示例      | 匹配示例                   |
| ---- | ------------------ | --------- | -------------------------- |
| `^`  | **匹配字符串开始** | `^Hello`  | "Hello world" 中的 "Hello" |
| `$`  | **匹配字符串结束** | `world$`  | "Hello world" 中的 "world" |
| `\b` | **匹配单词边界**   | `\bcat\b` | "cat" 但不匹配 "category"  |
| `\B` | **匹配非单词边界** | `\Bcat\B` | "mycategory" 中的 "cat"    |

### 4. 分组和捕获

| 符号      | 含义                         | 示例                                                         |
| --------- | ---------------------------- | ------------------------------------------------------------ |
| `(...)`   | **捕获分组**：记住匹配的文本 | `(abc)+` 匹配 "abcabc"                                       |
| `(?:...)` | **非捕获分组**：只分组不记忆 | `(?:abc)+` 匹配 "abcabc"                                     |
| `|`       | **或**操作                   | `cat|dog` 匹配 "cat" 或 "dog"                                |
| `\n`      | **反向引用**                 | `([a-z]) \1` 匹配 "a a", "b b". (引用第一个捕获组匹配到的内容，即必须和前面捕获的字母完全相同) |

 捕获与非捕获主要体现在使用上：

```
import re

text = "我的电话是010-88888888"

# 使用捕获组提取区号
m = re.search(r'(\d{3})-(\d{8})', text)
print(m.group(0))  # '010-88888888'（整体）
print(m.group(1))  # '010'（第1个捕获组：区号）✅ 能提取！
print(m.group(2))  # '88888888'（第2个捕获组：号码）
```

```
m = re.search(r'(?:\d{3})-(?:\d{8})', text)
print(m.group(0))  # '010-88888888'（整体）
print(m.group(1))  # ❌ 没有捕获组，无法提取区号
```

​	分组示例：

```
r'(?:cat|dog)+'  # ✅ 匹配 cat, dog, catdog, dogcat...
# 如果不加括号：r'cat|dog+' → 匹配 "cat" 或 "doggggg"（含义完全不同！）
```

## 常用正则表达式示例

### 1. 匹配邮箱地址

```regex
[\w.%+-]+@[a-zA-Z\d.-]+\.[a-zA-Z]{2,}
```

- `[\w.%+-]+`：用户名部分
- `@`：@ 符号
- `[a-zA-Z\d.-]+`：域名部分
- `\.`：字面点号
- `[a-zA-Z]{2,}`：顶级域名

### 2. 匹配中国大陆手机号

```regex
^1[3-9]\d{9}$
```

- 以 1 开头
- 第二位是 3-9
- 后面 9 位数字

### 3. 匹配日期（YYYY-MM-DD）

```regex
^\d{4}-(0[1-9]|1[0-2])-(0[1-9]|[12]\d|3[01])$
```

### 4. 北美电话号码

```regex
(\(\d{3}\) ?|\d{3}[-.]?)\d{3}[-.]?\d{4}
```

支持格式：`(800)123-4567`, `800.123.4567`, `800-123-4567` 等

## 在编程语言中使用

### Python 示例

```python
import re

text = "我的电话是 13812345678"
pattern = r'1[3-9]\d{9}'

# 查找所有匹配
matches = re.findall(pattern, text)
print(matches)  # ['13812345678']

# 替换
replaced_text = re.sub(pattern, "【电话号码】", text)

# 分割
parts = re.split(r'，', text)
```

## 进阶概念和技巧

### 1. 修饰符（Flags）

- `i`：忽略大小写
- `g`：全局匹配
- `m`：多行模式
- `s`：使 `.` 匹配包括换行符的所有字符

### 2. 零宽断言（Lookaround Assertions）

- `(?=exp)` **正向前瞻**：后面是 exp
  - `Windows(?=10|11)` 匹配 "Windows10" 中的 "Windows"
- `(?!exp)` **负向前瞻**：后面不是 exp
  - `Windows(?!10|11)` 匹配 "WindowsXP" 中的 "Windows"
- `(?<=exp)` **正向后顾**：前面是 exp
  - `(?<=\$)\d+` 匹配 "$100" 中的 "100"
- `(?<!exp)` **负向后顾**：前面不是 exp
  - `(?<!\$)\d+` 匹配 "I have 100$" 中的 "100"

### 3. 密码强度验证示例

```regex
/^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)[A-Za-z]\w{7,}$/
```

| 部分                  | 正则写法      | 含义说明                                                     |
| --------------------- | ------------- | ------------------------------------------------------------ |
| **行首锚定**          | `^`           | 匹配字符串的起始位置，确保检查从第一个字符开始               |
| **正向肯定前瞻（1）** | `(?=.*[a-z])` | 从当前位置（行首）开始检查，确保后续字符串中**至少存在一个小写英文字母**（`a-z`）。<br>此断言**不消耗字符**，仅做条件检查 |
| **正向肯定前瞻（2）** | `(?=.*[A-Z])` | 从当前位置（行首）开始检查，确保后续字符串中**至少存在一个大写英文字母**（`A-Z`）。<br>此断言**不消耗字符**，仅做条件检查 |
| **正向肯定前瞻（3）** | `(?=.*\d)`    | 从当前位置（行首）开始检查，确保后续字符串中**至少存在一个数字**（`0-9`）。<br>此断言**不消耗字符**，仅做条件检查 |
| **首字符规则**        | `[A-Za-z]`    | 匹配**第一个字符**，必须是一个英文字母（大写或小写均可）     |
| **后续字符规则**      | `\w{7,}`      | 匹配**至少7个**单词字符（`\w` = `[A-Za-z0-9_]`，即字母、数字、下划线） |
| **行尾锚定**          | `$`           | 匹配字符串的结束位置，确保整个字符串都被匹配，没有多余字符   |

| 要求                       | 说明                    |
| -------------------------- | ----------------------- |
| ✅ 至少1个小写字母          | `a-z`                   |
| ✅ 至少1个大写字母          | `A-Z`                   |
| ✅ 至少1个数字              | `0-9`                   |
| ✅ 首字符为字母             | `A-Z` 或 `a-z`          |
| ✅ 总长度 ≥ 8               | 首字母1个 + 后续至少7个 |
| ✅ 仅允许字母、数字、下划线 | `\w` 决定               |

## 重要细节说明

### 字符集内的特殊字符

在字符集 `[]` 内：

- **点号 `.` 不需要转义**（`[.-]` 匹配点号或连字符）
- **连字符 `-`** 放在开头或结尾时不需要转义
- **右括号 `]`** 需要转义：`[\]]`
- **脱字符 `^`** 在开头表示取反，否则是普通字符

### 转义规则

- **在纯正则表达式**中使用单反斜杠：`\(` `\d`
- **在代码字符串**中使用双反斜杠：`\\d` `\\(`
- **推荐使用 raw 字符串**：Python 的 `r''`，避免转义问题

## 总结

正则表达式是强大的文本处理工具，通过组合简单的元字符可以构建复杂的匹配模式。关键是要理解：

- 字符匹配：用什么匹配什么
- 数量限定：匹配多少次
- 位置限定：在哪里匹配
- 分组捕获：如何组织和引用匹配内容

掌握这些基础概念后，再学习进阶的零宽断言等特性，就能应对大多数文本处理需求。
