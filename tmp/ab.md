## 1. 问题描述

Alice 在两张纸条上分别写下两个**不同的实数**，两个数都在 0 到 1 之间。她把纸条分别装进两个不同的信封。

Bob 随机选择一个信封打开，看到里面的数字。然后他必须判断：这个数字是两张纸条中**较大**的那个，还是**较小**的那个。

问题：Bob 有没有办法，在 Alice 和他玩这个游戏时，期望正确率**严格大于一半**？

直觉上，这似乎不可能。Alice 可以任意选两个数，Bob 只看到一个数，另一个数完全未知，正确率接近 1/2。但正确答案是：

> **有。Bob 可以做到期望正确率严格大于 1/2。**

---

## 2. 问题解决

Bob 的策略如下：

1. 在打开信封**之前**，Bob 自己偷偷随机生成一个数 r，r 在 (0,1) 上均匀分布。
2. 打开信封，看到数字 x。
3. 如果 x > r，Bob 猜“x 是较大的那个数”。
4. 如果 x < r，Bob 猜“x 是较小的那个数”。
5. 如果 x = r（概率为零），随便猜即可。

每一轮游戏，Bob 都重新独立随机生成一个新的 r，并且不让 Alice 知道。

### 2.1 分类分析

设 Alice 这一轮写的两个数为

$$
a < b
$$

Bob 随机打开一个信封，所以看到 a 或 b 的概率各为 1/2。Bob 随机选的阈值是 r。

我们按照 r 是否落在 (a,b) 之间来分类。

| r 的位置  | Bob 看到 a | Bob 看到 b |
| --------- | ---------- | ---------- |
| a < r < b | 赢         | 赢         |
| r < a < b | 输         | 赢         |
| a < b < r | 赢         | 输         |

解释：

- **情况一：a < r < b。**
  - 如果 Bob 看到 a，因为 a < r，他猜“较小”，正确。
  - 如果 Bob 看到 b，因为 b > r，他猜“较大”，正确。
  - 所以只要 r 落在 (a,b) 内，Bob **无论看到哪个都赢**。

- **情况二：r < a < b。**
  - 看到 a：a > r，Bob 猜“较大”，但 a 其实是较小，错。
  - 看到 b：b > r，Bob 猜“较大”，正确。
  - 一错一对，胜率一半。

- **情况三：a < b < r。**
  - 看到 a：a < r，Bob 猜“较小”，正确。
  - 看到 b：b < r，Bob 猜“较小”，但 b 其实是较大，错。
  - 一错一对，胜率一半。

因此，Bob 的总胜率为：

$$
P(\text{赢})
= P(r \in (a,b)) \cdot 1
+ P(r \notin (a,b)) \cdot \frac12
$$

由于 r 在 (0,1) 上均匀分布，而 (a,b) 是 (0,1) 的子区间，所以

$$
P(r \in (a,b)) = b - a
$$

于是

$$
P(\text{赢})
= (b-a) + \bigl(1-(b-a)\bigr)\cdot \frac12
= \frac12 + \frac{b-a}{2}
$$

因为 Alice 写的两个数不同，所以 b - a > 0。因此

$$
P(\text{赢}) = \frac12 + \frac{b-a}{2} > \frac12
$$

Bob 的期望正确率**严格大于一半**。

### 2.2 关于 r 的重要说明

- 每一轮都应该重新独立随机生成 r。
- 如果 Bob 固定一个 r，而 Alice 知道或猜到了这个 r，她可以故意选两个都在 r 同一侧的数，使 Bob 的胜率退化为 1/2。
- 每轮重新随机 r，可以保证 Alice 无法针对 Bob 的策略。
- Bob 不需要知道 Alice 选数的分布，也不需要假设 Alice 是随机选数。无论 Alice 怎么选，只要她选的两个数不同，Bob 的胜率都严格大于 1/2。

## 3. 为什么反直觉

这个结论之所以让人感觉反直觉，是因为它看起来像“凭空获得了信息”。Bob 只看到一个数，另一个数完全未知，他凭什么能超过一半正确？

关键在于区分两件事：

### 3.1 Alice 不是随机选数，而是任意选数

如果 Alice 是**独立均匀随机**地在 (0,1) 中选两个数，那么 Bob 看到任意一个数后，另一个数比它大或小的概率本来就各一半。Bob 没有任何优势。

但题目中 Alice 只是“写两个不同的实数”。她可以故意选得非常接近，也可以选得相差很大。Bob 不知道她怎么选。

Bob 的随机阈值 r 的作用，是把 Alice 的“任意选择”转化为 Bob 的“概率优势”。

### 3.2 实数轴上总有正长度的区间

Alice 选的两个数 a < b 之间，总有一段长度为正的区间 (a,b)。Bob 随机生成的 r 有正概率 b - a 落进这个区间。

一旦 r 落进 (a,b)，Bob 就**必赢**。如果 r 没落进去，Bob 至少不亏，胜率仍是一半。

所以 Bob 的总胜率是

$$
\frac12 + \frac{b-a}{2}
$$

Alice 可以把 b - a 选得任意小，从而把 Bob 的优势压得任意小，但她**永远无法把优势压到零**，除非她允许 a = b。而题目要求两个数不同。

### 3.3 无分布假设的优势

这个策略还有一个漂亮之处：Bob 不需要知道 Alice 的选数分布，也不需要知道 Alice 是不是随机选数。哪怕 Alice 故意针对 Bob 的策略来选数，只要 Bob 每轮重新随机 r，他的胜率仍然严格大于一半。

这就是所谓的“无分布假设”策略：不依赖对方如何随机，只利用实数轴上的区间结构。

### 3.4 直觉的误区

直觉容易这样想：

> “Bob 只看到一个数，另一个数他什么都不知道，怎么可能超过一半？”

但 Bob 并不是在猜“另一个数具体是多少”。他只是在猜“自己看到的这个数在两者中偏大还是偏小”。而他的随机阈值 r 给了他一个正概率，使他在某些情况下**无论看到哪个都猜对**。这个“双赢”的概率虽然可能很小，但始终为正，因此总胜率严格大于一半。

换句话说：

> Alice 可以把 Bob 的优势压到任意小，但永远无法把它压到零。

这就是这个问题的反直觉之处，也是它最迷人的地方。
