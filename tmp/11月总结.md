**问题定位路径：**
`时间不一致` → `验证训练数量` → `检查nSpeedUp属性` → `查库确认值` → `定位来源（重刑犯）` → `发现CalcAttrExpVal取值为0` → `追溯至属性过滤器` → `确认重刑犯被过滤`。

**解决方案与贡献：**
不仅修复了BUG，更完善了属性系统的过滤器配置逻辑，为后续新增属性来源建立了规范。

### 3.2 系统机制深度剖析
- **疯狂乔伊怪物行为链：** 完整分析了从`RPC`参数修改 → `init`扫描 → 创建据点(`MonsterStronghold`) → 设置定时器 → 发起行军(`RunMarchByInner`) → 触发战斗(`ExecuteSlgBattleV3`)的全过程。
- **IoC模块机制：** 理解了`IoC`通知如何替代事件通知，并在`GameCondition`等模块中实现计数管理。
