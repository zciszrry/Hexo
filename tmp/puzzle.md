#### 12.05

​	在一个岛上，有13只紫色变色龙、15只黄色和17只栗色变色龙。当两只不同颜色的变色龙相遇时，它们都会变成第三种颜色（如紫色+黄色变为两只栗色）。是否存在一系列成对相遇后，所有变色龙颜色相同？

​	若最终状态能达到同一种颜色，设为颜色C。

​	则前一种状态必为：颜色A和B各一只。

​	即，至少有一个时刻，A个数 = B个数。

​	设初始时，A < B。为了使A = B，必须经过 " B + C = 2A" 的步骤，即B每次减一时A就会加二（在C数量充足时），即A和B的数量间隔必须为3的倍数。

​	设A和B和C的数量初始为 x 和 x+3n 和 c ，为使C的数量充足，应进行 x次"A + B = 2C"，此时数量分别为0，3n，c+2x。

​	此后变化为：(2，3n-1，c+2x-1) -> (0，3n-3，c+2x+3) -> (2，3n-4，c+2x+2) -> …… -> （0，0，c+2x+3n）

​	显然，c和x不同时为0时，则初始时A和B的数量间隔为3的倍数时，必定能达到最终情况。

​	例：（0，1，6）-（2，0，5）-（0，4，3）-（2，3，2）-（0，7，0）

​	例：（1，4，9）-（3，3，8）-（0，0，14）

##### 模3不变量：

​	**任何一次相遇**都等价于让**三个颜色的数量模 3 各减去 1**（只是被选中的两种颜色确实减 1 实际数量，第三种实际数量加 2，但模 3 是减 1）。

​	此题初始余数：(1,0,2)

​	每次所有余数减 1 mod 3：
​	第一次相遇后 → (0,2,1)
​	第二次相遇后 → (2,1,0)
​	第三次相遇后 → (1,0,2) 回到初始模 3 状态

​	即可达的余数状态集合是 {(1,0,2), (0,2,1), (2,1,0)} 这 3 种。而此题的最终状态如（45，0，0）对应的余数状态是（0，0，0）不可达。

​	上面提到的“初始时A和B的数量间隔为3的倍数时”实际上是，初始余数状态有两者余数相同。

​	若三者初始余数都不相同（即0，1，2的组合），最终余数状态必为（0，0，0），因为0+1+2 mod 3 = 0，即必不可达。

​	即，初始不存在3的倍数的间隔时，必不可能为最终状态。
