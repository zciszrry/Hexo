1. 模块概述

buildquicklist 模块是 majorserver 中的核心业务模块，负责管理游戏中的建筑快捷队列系统（Building Quick List / Building Slot）。 该系统允许玩家拥有多个建造/研究/治疗等类型的工作队列槽位，每个槽位可以被激活（临时或永久）并执行对应类型的工作任务。

模块的核心职责包括：

职责说明
队列槽位管理创建、激活、关闭队列槽位
工作任务调度向空闲槽位分配工作、注册定时任务、处理完成回调
时间加速减少工作时间、重新调度定时器
联盟协助公会帮助请求/响应、减免时间
状态推送实时向客户端推送队列状态变更
GM 调试强制完成、恢复异常队列等

5.2 数据加载流程

findQuickListData 函数是数据加载的核心入口：

  1. 尝试从数据库读取玩家的队列数据（StoreGet）
  2. 若不存在（首次），则初始化并插入数据库（StoreInsert）
  3. 根据配置表 ConfQuickQueue 遍历所有应有的队列槽位
  4. 对于配置中存在但数据中缺失的槽位，自动创建（确保配置扩展时自动补全）
  5. 重置数据变更标记后返回数据对象
注意：每次加载数据时都会与配置表对比，自动补全缺失的队列槽位，保证了配置热更新时的数据兼容性。

5.3 对象池化

TQuickListObj 使用 sync.Pool 进行对象池化管理（buildquicklist_obj_auto.go）， 通过 NewTQuickListObj() 从池中获取、Release() 归还池中，减少 GC 压力。 生命周期方法包括 CheckUpdate、Update、Release、Put等。

6. 核心业务逻辑

6.1 队列激活 — onQuickListActive

处理队列槽位的激活状态变更，支持以下状态转换：

目标状态处理逻辑
ESlotActivateStateNo 从 Hide 状态转为未激活（用于显示控制）
ESlotActivateStateForever 永久激活，无需定时器回收
ESlotActivateStateTemporary 临时激活：首次注册定时任务 Task_QuickListActive，到期自动停止；重复激活时累加时长并重新调度定时器

6.2 工作任务分配 — onQuickListWork

查找空闲槽位 → 注册定时任务 → 计算工作状态 → StartWork & Push

关键实现细节：

  • 通过 _getIdleQuickListUnit 按类型查找空闲、已激活的槽位
  • 科研类型特殊处理：通过 _getIdLeScienceListUnit 按建筑映射到固定队列ID
  • 使用 task.Add 注册毫秒级精度的定时任务
  • 最小工作时长保证为 1 秒（duration <= 0 时兜底）
  • 通过 _calSlotWorkState 计算是否可请求公会帮助

6.3 工作完成回调 — taskWorkCompleted

func taskWorkCompleted(params WorkCompleteParams) error {
    // 带重试的异步处理（5次重试，1秒间隔）
    majorserver.CtxRunProcessFuncRetryWithLockTimeout(...)
    // 1. 锁定用户数据
    // 2. 校验 BuildingInsId 一致性（防止取消后残留定时器触发）
    // 3. 派发 EventQuickListWorkCompleted 事件
    // 4. 停止工作、推送状态
}

6.4 时间加速 — onSubWorkTime

支持对指定队列或所有建造队列进行时间减免：

  • 修改队列单元的剩余时间 SubWorkTime
  • 重新计算结束时间，调用 task.ReSched 更新定时器
  • 若加速后已超时，立即将定时器调度到当前时间（触发完成）
  • 派发加速事件 EventQuickListWorkTimeChange

6.5 取消工作 — onCancelWork

取消队列当前工作：删除定时任务、停止工作状态、推送更新。

6.6 空闲槽位查找 — _getIdleQuickListUnit

查找算法：遍历指定类型的所有槽位，筛选出激活且空闲的槽位，若有多个空闲则按配置的 Sort 字段排序后取第一个。

6.7 工作状态计算 — _calSlotWorkState

根据以下条件判定槽位的工作子状态：

// 优先级从高到低：
1. 未激活 → 保持当前状态
2. 支持联盟帮助 & 有公会 & 治疗队列额度判定 → BusyHelp
3. 免费加速时间 > 0 → BusyFree
4. 默认 → BusyNoHelp

10. 状态机

10.1 激活状态（EBuildingSlotActivateState）

Hide（隐藏） → No（未激活/可见） → Temporary（临时激活） → Forever（永久激活）

状态只能单向升级（curState > targetState 会拒绝），临时激活支持叠加时长。

10.2 工作状态（EBuildingSlotWorkState）

状态含义
ESlotWorkStateIdle空闲，可分配新工作
ESlotWorkStateBusyHelp工作中，可请求联盟帮助
ESlotWorkStateBusyNoHelp工作中，不可帮助（已帮助或无公会）
ESlotWorkStateBusyFree工作中，免费加速可用

10.3 工作类型（EBuildingState — workState）

记录在 WorkInfo.WorkState 中，标识当前队列执行的具体操作类型，如：

  • Normal — 无工作（空闲标记）
  • UnlockLandBox — 解锁地块（在 buildingId 查找时会被跳过）
  • Delete — 拆除建筑
  • 其他建造、升级、研究、治疗等状态...
