### 重装系统后所配置的环境/工具

​	Wsl/CentOs7环境：

​		yum源不可用，需要换阿里源；还需要更改DNS服务器配置（但初入公司时没有碰到这问题）

```
备份原有的镜像源配置文件：
sudo mv /etc/yum.repos.d/CentOS-Base.repo /etc/yum.repos.d/CentOS-Base.repo.backup

下载新的镜像源配置文件：
以阿里云镜像源为例：
sudo wget -O /etc/yum.repos.d/CentOS-Base.repo http://mirrors.aliyun.com/repo/Centos-7.repo

若wget未安装：
sudo curl -o /etc/yum.repos.d/CentOS-Base.repo http://mirrors.aliyun.com/repo/Centos-7.repo

(
9.22复发:
	需修改配置为：
		#mirrorlist=http://mirrorlist.centos.org?arch=$basearch&release=7&repo=sclo-rh
		#baseurl=http://mirror.centos.org/centos/$releasever/sclo/$basearch/rh/
		baseurl=http://vault.centos.org/centos/$releasever/sclo/$basearch/rh/
	涉及文件：/etc/yum.repos.d/CentOS-SCLo-scl-rh.repo	/etc/yum.repos.d/CentOS-SCLo-scl.repo
)

检查DNS配置：
cat /etc/resolv.conf

添加DNS配置：
nameserver 8.8.8.8    # Google 公共 DNS
nameserver 114.114.114.114 # 国内移动/电信通用 DNS
nameserver 1.1.1.1    # Cloudflare DNS


```
